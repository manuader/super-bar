# SuperBar — implementation plan (2026-09-02)

Executed in this order; each step ends with a green build/test.

## Phase 0 — scaffolding
1. Repo: `.gitignore`, MIT license, README, Makefile, `project.yml`
   (XcodeGen), CI workflow, project skills in `.claude/skills/`.
2. `Packages/SuperBarKit` (SwiftPM, macOS 14, Swift 5 language mode,
   strict-concurrency=targeted) with an empty test target.

## Phase 1 — SuperBarKit core (TDD: tests first, then implementation)
3. `MenuModel`: `MenuNode`, `KeyEquivalent` (+ glyph/virtual-key tables,
   modifier mask decoding), `MenuSnapshot`, flattening, `displayTitle`.
4. `Fuzzy`: `FuzzyMatcher.score(query:in:) -> Match?`, `ListSearch`,
   `OutlineSearch` (ancestor retention, expansion set, best match).
5. `Frecency`: `RecentsStore` (record, score, top(for:), dynamic-title
   fallback, JSON persistence, debounced save).
6. `Rules`: `Rule`, `RuleSubject`, `RuleEngine.apply(rules:, to:)`.
7. `Scripts`: `ScriptItem`, `ScriptsLibrary.scan(root:)`, `ScriptRunner`
   interpreter selection, `ScriptsWatcher` (FSEvents).
8. `Themes`: `Theme`, `BuiltInThemes`, `ThemeStore` codec.
9. `Preferences`: typed keys, defaults, migration-free.
10. `MenuSource` protocol, `FixtureMenuSource` (Notes-like tree for tests
    and snapshots), `AXMenuSource` (traversal, press, reveal, help search,
    permission check, timeout → `.busy`).

## Phase 2 — App
11. XcodeGen project: app target (LSUIElement, Info.plist keys, entitlements,
    automatic signing via `DEVELOPMENT_TEAM` env), CLI target copied into
    `Contents/MacOS`, unit-test target for the app.
12. `AppDelegate`: single instance, status item, hot key, palette, settings,
    permission window, `open -ga` support (`applicationShouldHandleReopen`).
13. `HotKeyCenter` (Carbon) + `ShortcutRecorderView` (keyboard-driven).
14. `MenuCache` (per pid snapshot, stale-while-revalidate, invalidate on app
    termination / menu bar title changes).
15. `SearchSession` (root/scoped/search state, mode, expansion, selection,
    quick-select numbering, persisted search state).
16. Palette: `PalettePanel`, `PaletteViewController`, `HeaderView`,
    `ScopeBarView`, `MenuRowView`, `SectionHeaderView`, `FooterView`,
    `EmptyStateView` (fruitless / error / permission / skeleton), theming.
17. Activation: press with retry, reveal, scripts, help fallback, recents.
18. Settings window: General, Appearance (+ theme editor), Rules
    (+ NSPredicateEditor sheet with `Predicate.strings`), Scripts, About.
19. Snapshot harness (`SUPERBAR_FIXTURE`, `SUPERBAR_QUERY`,
    `SUPERBAR_MODE`, `SUPERBAR_SNAPSHOT`) → `make snapshot` renders PNGs.
20. App icon generated by `scripts/make-icon.swift` into the asset catalog.

## Phase 3 — verification and delivery
21. `swift test`, `xcodebuild build`, snapshot review of root, search-list,
    search-outline, scoped, fruitless, permission states in light and dark.
22. Launch the app locally (`make run`), confirm status item + hot key.
23. README (install, permissions, shortcuts, scripts, rules, CLI, building).
24. Commit history by phase; push to `github.com/manuader/super-bar`.
